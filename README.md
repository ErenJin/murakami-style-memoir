# 村上式青春回忆写作（murakami-style-memoir）

以村上春树（林少华译本）的文体风格，书写个人青春回忆、随笔、短篇散文的**系列创作技能**。

> 把零散的青春记忆，变成克制、疏离、充满物象与留白的回忆散文。

---

## 这是什么

一个面向 AI 助手的 **Skill 技能包**（Agent Skill）。它定义了一套完整的写作方法论：

- **村上式文体基准**：林少华译本的句式、比喻、留白、禁忌——不是"模仿村上"的泛泛而谈，而是一份可逐项自检的风格清单（见 `references/style-guide.md`）。**本基准根据作者本人的阅读喜好作了特定强化**——重点落在情感描写、物象白描与"物哀/遗憾"两大情感坐标上，让成文天然贴近那些最打动人的村上笔触。
- **严谨的创作流程**：篇幅确认 → 照片采集 → 情绪双问 → 时间/年龄校准 → 结构规划 → 写作 → 自检 → 归档，共 8 步。
- **只写事实，不编情节**：正文只用你口述、照片与素材库中的真实内容，AI 不得虚构你未提及的事件、对话、动作。
- **素材库项目级隔离**：skill 本身不存素材，素材跟着具体项目走，不同文章系列互不污染。

## 核心特性

| 特性 | 说明 |
|------|------|
| 🖐️ 仅手动调用 | 不会因"回忆""青春"等关键词自动触发，必须由你明确发出写作指令 |
| 📸 照片优先 | 人物/地点/送物场景以照片为特征来源，写谁像谁 |
| 🎭 情绪双问 | 必问"当时"与"现在"两层心情，把笼统情绪锚定到村上意象坐标 |
| ⏱️ 时间年龄校准 | 事件时间、人物年龄必核，敏感信息自动模糊化 |
| 🚫 不编情节 | 未提及的事一律不写，宁缺毋滥，只做村上式润色 |
| 📂 素材项目隔离 | skill 可复用，素材在各项目文件夹独立累积 |

## 安装

### WorkBuddy（推荐）

将本仓库 `murakami-style-memoir` 目录复制到用户级 skills 目录：

```bash
# macOS / Linux
cp -r murakami-style-memoir ~/.workbuddy/skills/

# Windows
# 复制 murakami-style-memoir 到 %USERPROFILE%\.workbuddy\skills\
```

### 其他 AI 助手

将 `SKILL.md` 及其 `references/` 目录作为技能包引入你的 AI 助手（支持 Agent Skill 的助手均可），或将 `SKILL.md` 内容直接作为系统指令附加。

## 调用方式

**仅支持手动调用，禁止自动触发。** 直接对你的 AI 助手说：

- "用村上的风格写一段回忆……"
- "按村上风格改这段文字：……"
- "继续写上一篇回忆"
- "按村上风格润色这段：……"

## 写作流程（8 步）

```
Step 1  篇幅确认     → 短文单篇 / 长篇先定大纲（核心故事、时间跨度、重要事件）
Step 2  照片采集     → 人物/地点/物件照片（先确认读图能力）
Step 3  情绪双问     → 当时的心情 + 现在回望的心情
Step 4  素材库读写   → 项目级 materials.md（不存在则按模板创建）
Step 5  时间年龄确认 → 事件年份/季节、人物年龄，缺失必问
Step 6  拟定结构     → 触发物切入 → 场景片段 → 物象收束（不展示给用户）
Step 7  写作         → 对照 style-guide.md，只润色不编情节
Step 8  交付归档     → 成文 + 手法说明 + 定稿后写回项目素材库
```

## 目录结构

```
murakami-style-memoir/
├── SKILL.md                    # 技能主文件（入口，含完整流程指令）
├── references/
│   ├── style-guide.md          # 村上式文体基准（唯一风格依据，写作必载）
│   └── materials-template.md   # 素材库模板（人物/地点/物件/事件/情绪/特征登记）
├── materials/
│   └── README.md               # 说明：素材库为项目级，不存放于 skill 内
└── examples/
    ├── example-1-railway.md    # 虚构示例：如何把口述素材写成村上式短文
    └── example-2-old-photo.md  # 虚构示例：物品触发与环形结构
```

> ⚠️ 实际写作时，素材库应位于**当前项目文件夹**：`{你的项目}/.workbuddy/materials/murakami-style-memoir/materials.md`，而非 skill 目录内。

## 使用示例

`examples/` 目录下有虚构的输入→输出示例，展示素材如何被转化为村上式短文。每个示例都标注了使用的村上手法（触发物切入、身体化情绪、物哀收束、环形结构等）。
