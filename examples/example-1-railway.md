# 示例 1：从口述素材到成文（铁路小站）

> ⚠️ **本示例为虚构内容**，仅用于演示技能如何工作。所有人物、地点、事件均为虚构，不代表任何真实经历。

## 用户口述的素材（输入）

> 我爷爷在县城火车站当了一辈子扳道工。我小时候暑假总去那儿玩，站台尽头有一棵老槐树。2003 年火车站改造，旧站房拆了，爷爷也退休了。那棵树被移走了，听说没移活。

## 素材结构化（Step 1-5 确认）

- **篇幅**：短文
- **时间/年龄**：2003 年夏，我 11 岁，爷爷 62 岁
- **情绪（当时）**：无忧无虑，觉得暑假永远过不完
- **情绪（现在）**：怅惘而平静——"想来也并无更好的办法"那种
- **照片**：无（用户口述）

## 成文（Step 7 输出）

**《站台尽头的槐树》**

县城火车站的站台尽头，长着一棵老槐树。我爷爷在那里当了四十二年扳道工。小时候放暑假，我常坐在槐树底下看他摇信号旗——旗子挥下去，绿皮车就哐当哐当地进站了。

那时我觉得暑假是取之不尽的。爷爷的搪瓷缸里泡着浓茶，我从没见过他把茶喝完。蝉鸣在头顶响成一片，铁轨被晒得发烫，空气里有股枕木和煤渣的味道。他并不怎么说话，只是抽烟，烟灰弹进风里，转眼就不见了。

二〇〇三年，火车站改造。旧站房拆了，爷爷也退了休。那棵老槐树被连根移走，听说换了个地方，到底没活过来。

后来的事我没有再问。每年夏天蝉还是会响，只是不再有那样一棵树，也不再有那样一个下午了。想来也并无更好的办法。人也好，树也好，都敌不过时代把旗子一挥——进站了，就该下车了。

## 本文使用了哪些村上手法

| 手法 | 落点 |
|------|------|
| 触发物切入 | 从"站台尽头的槐树"进入记忆 |
| 物象白描 | 搪瓷缸、信号旗、蝉鸣、枕木煤渣的气味 |
| 身体化情绪 | 不写"我怀念爷爷"，写"烟灰弹进风里，转眼不见了" |
| 物哀收束 | "想来也并无更好的办法。人也好，树也好……" |
| 瑕疵物象 | "那棵树被移走，听说没移活"——残缺才载得住岁月 |
| 以物象收尾 | 结尾落在"进站了，就该下车了"，不点破 |
