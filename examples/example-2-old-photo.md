# 示例 2：物件触发与环形结构（旧照片）

> ⚠️ **本示例为虚构内容**，仅用于演示技能如何工作。所有人物、地点、事件均为虚构，不代表任何真实经历。

## 用户口述的素材（输入）

> 搬家时翻出一张照片，是 1999 年秋天拍的，我和两个同学站在学校门口。照片右下角卷了一角。那个帮我拍照片的同学，毕业以后就再没联系了。听说他去了北方。

## 素材结构化（Step 1-5 确认）

- **篇幅**：短文
- **时间/年龄**：1999 年秋，我 16 岁，拍照片的同学 17 岁
- **情绪（当时）**：稀松平常，不觉得那天有什么特别
- **情绪（现在）**：遗憾浮上来——"为什么当年没有继续联系呢"
- **照片**：有（用户提供旧照片，仅描述照片特征：右下角卷角）

## 成文（Step 7 输出）

**《右下角卷了的照片》**

搬家的纸箱最底下，有一张照片。右下角卷了一角，像被人反复折过，又像那年秋天的风一直吹着它，没有停下来。

照片上是学校门口，1999 年。我十六岁，站在中间，左边右边的同学叫什么名字，我已经记不全了。帮我们拍照片的那个人站在镜头后面，喊了一声"茄子"，然后按下快门。他喊得最大声，照片里却唯独没有他。

那天的阳光很好，好到我们谁也没觉得那天有什么特别。后来的事情你们都猜得到——毕业，各奔东西，电话号码换了一茬又一茬。帮我拍照的那个人去了北方，起初还有两封信，后来连信也没了。

如今照片右下角卷了，像那句话说到一半，没有说完。

## 本文使用了哪些村上手法

| 手法 | 落点 |
|------|------|
| 物件触发切入 | 从"纸箱最底下的照片"进入记忆 |
| 环形结构 | 开头"右下角卷了一角"→ 结尾"如今照片右下角卷了"同一物象换了重量 |
| 遗憾的时间观 | 不写"我后悔"，写"起初还有两封信，后来连信也没了"——遗憾是浮上来的 |
| 留白 | "那句话说到一半，没有说完"——不解释是哪句话 |
| 不评判 | 不说"我该珍惜"，只写事实 |
| 光年错位（母题） | 照片里的人是 1999 年的光，如今只剩下影像 |
